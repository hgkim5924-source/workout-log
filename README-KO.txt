WORKOUT LOG v2 - 운동 라이브러리 업데이트
============================================

이번 버전 추가 기능
- 가슴/등/어깨/이두/삼두/하체/복근/유산소/기타 분류
- 70여 종의 기본 운동 라이브러리 및 검색
- 운동별 주 타겟/보조 근육/운동 도구/간단한 수행 방법 안내
- 근육 부위를 강조한 인체 도식
- 사용자 운동 직접 추가 및 기기 내 저장
- 기존 운동/신체 기록 유지
- 사용자 추가 운동도 JSON 백업/복원에 포함
- 오프라인 캐시 버전 갱신

배포 방법
1. GitHub 저장소 https://github.com/hgkim5924-source/workout-log 를 엽니다.
2. 저장소 첫 화면에서 Add file > Upload files 를 누릅니다.
3. 이 ZIP을 PC에서 압축 해제합니다.
4. 압축 해제한 폴더 안의 파일 8개를 모두 선택해 GitHub 업로드 영역에 끌어다 놓습니다.
5. 아래쪽 Commit changes 를 눌러 main 브랜치에 반영합니다.
6. 1~3분 기다린 뒤 아이폰에서 WORKOUT LOG를 완전히 종료하고 다시 실행합니다.
7. 새 버전이 보이지 않으면 Safari에서 배포 주소를 열어 새로고침한 뒤 홈 화면 앱을 다시 실행합니다.

중요
- 기존 IndexedDB 저장소 이름과 키(logs/body)를 유지하므로 기존 기록을 지우지 않습니다.
- 기록 데이터는 아이폰 내부에만 저장됩니다. 업데이트 전 설정에서 JSON 백업을 권장합니다.
- 운동 그림은 운동 부위를 강조한 자체 제작 인체 도식입니다. 개별 운동 동작을 정확히 보여주는 해부학 일러스트는 후속 확장 대상으로 남겨두었습니다.
